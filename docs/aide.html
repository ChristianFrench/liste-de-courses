Questions fréquentes

Faut-il créer un compte ?

Non. On utilise Emplettes seul sur son appareil, ou en foyer : un code de partage suffit pour rejoindre les autres membres.

Mes listes sont-elles envoyées quelque part ?

Seul, rien ne quitte l'appareil. En foyer, les listes passent d'un appareil à l'autre par le serveur d'Emplettes, chiffrées avec le code du foyer : le serveur ne peut pas les lire.

L'application marche-t-elle sans réseau ?

Oui. Tout est enregistré sur l'appareil ; les changements partent vers le foyer dès que le réseau revient.

Comment la liste suit-elle l'ordre du magasin ?

Pendant les courses, l'ordre dans lequel vous cochez les articles apprend votre parcours dans ce magasin. Les fois suivantes, la liste se range dans cet ordre.

Comment être prévenu d'un message du foyer ?

Sur Android, acceptez les notifications au premier lancement : les messages arrivent même application fermée. Dans le navigateur : Gérer › Foyer › Messages › « Recevoir les notifications sur cet appareil ».

Le catalogue change-t-il ?

Oui : il s'améliore pour tous les foyers. Chaque nouvelle version s'ajoute à votre catalogue au lancement, sans retirer ce qui sert à vos listes. Sa version s'affiche dans Gérer.

Comment garder mes données en sécurité ?

Une copie est faite à chaque étape importante. « Sauvegarder maintenant » (Gérer › Paramètres › Données › Sauvegardes) donne un fichier à garder ailleurs.

Vos données

Les listes restent sur vos appareils. Dans un foyer, elles passent d'un appareil à l'autre chiffrées avec le code du foyer. Aucune publicité, aucun compte, aucune donnée revendue.
