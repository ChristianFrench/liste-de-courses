En quatre étapesComment ça marche

1

Je paramètre

Une fois pour toutes : seul ou en foyer, les membres, les magasins, les couleurs de l'application.

2

Je prépare ma liste

Je tape trois lettres, l'article se range sous son secteur. Ou je pars d'une liste type, d'une course passée, du texte d'un mail.

3

Je la valide

« Liste prête » : un commentaire pour celui qui part, et le mail au foyer si besoin.

4

Je fais mes courses

La liste suit l'ordre de mes allées. Je coche, je mets en pause, je reprends, puis je garde le ticket.

Une nouvelle liste : par secteur, simple, depuis une liste type, une course passée ou un texte.

Pour tout le foyerUne liste, plusieurs mains

  • Un foyer, un code : sans compte ni mot de passe, chacun rejoint le foyer avec son code de partage.
  • Les listes se partagent d'un appareil à l'autre, chiffrées avec le code du foyer, même après avoir été modifiées hors connexion.
  • Le parcours est personnel : chaque membre a son ordre des allées, dans chaque magasin.
  • Lisible partout : grands caractères, police conçue pour la lisibilité, gestes simples d'une main.
  • Vos données restent chez vous, avec des sauvegardes automatiques.
