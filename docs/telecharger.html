Télécharger

Emplettes sur téléphone Android ou sur PC Windows.

Android

Le fichier APK à installer sur le téléphone.

  1. Touchez « Télécharger l'APK ».
  2. Ouvrez le fichier téléchargé.
  3. Android demande d'autoriser l'installation depuis le navigateur : acceptez.
  4. Au premier lancement, acceptez les notifications : les messages du foyer arriveront directement.
Télécharger l'APK

Windows

Un programme d'installation, qui sert aussi aux mises à jour.

  1. Téléchargez et ouvrez « Emplettes-Installation.exe ».
  2. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires » › « Exécuter quand même ».
  3. Pour mettre à jour, refaites la même chose : vos listes et votre foyer sont conservés.
